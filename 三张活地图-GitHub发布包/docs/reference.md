# 三张活地图作业参考样本：有据可查的课程资料问答（RAG）



> 这是 2026-10-17 制作的参考样本，不是某个学生小组已经完成七周实践的成果。事实与来源、样本分析、合成实验、本校待核实内容分别标注。你们仍需完成真实课程核查、独立互评、持续更新与成员贡献。



## 1. 选题与研究边界

研究学生如何从已获授权的课程资料中，找到能核对出处的答案。以“这门课的大作业到底交什么”为典型任务，串起资料、检索、生成、引用与评价。主取向为 AI 工程师，兼顾科学家的证据意识与设计师的使用体验。暂不展开从零训练大模型、复杂多智能体、商业上线和真实校内数据接入。



希望帮助同学理解：一个看似简单的“课程问答”为什么需要资料管理、检索、模型、引用、评价和人参与；知识、生态和分析方法如何相互影响。



典型任务：依据获授权的作业说明，回答“最终到底交什么”。以用户提供的本次作业为例，答案应涵盖持续可访问的网站、三图、地图相关 AI、重要内容来源与核实状态、中期以来更新、反馈处理、认识修正、未知与后续入口、成员贡献，逐条回到作业第十部分。不能凭模型记忆补造截止日期或本校课程。



主取向：AI 工程师。科学家取向体现为对照、反例与证据记录；设计师取向体现为可核查引用、拒答表达与独立浏览反馈。



## 2. 领域地图：知识、工具、学习如何连接

整体主线：资料与版本 → 切分与定位 → 检索 → 重排（按需） → 生成与拒答 → 引用核查 → 分层评价。文本嵌入为语义检索提供表示，Faiss 提供向量搜索能力，Dify / RAGFlow 提供工程编排路线。可以从关键词检索或全文阅读做基线，不预设每个任务都要调用大模型。



### RAG｜先找资料，再组织回答

内容性质：方法概括。

含义：把与问题相关的外部资料提供给生成模型，再组织答案。就像开卷答题：先翻到相关页，再回答，但翻到书并不保证读对。

作用与关系：让答案可以依赖可更新的资料，而不仅依赖模型参数中的知识。

例子：问“大作业要交什么”，先找作业说明的提交条款，再逐条回答并指向原文。

局限：检索可能漏掉关键条款，资料可能过期，模型也可能曲解证据；RAG 不保证消除错误。

学习基础：先理解任务、资料与输出之间的数据流；无需先掌握训练大模型。

下一步：比较全文阅读、关键词检索和检索后生成，先做一个无需模型的检索基线。

来源：[S01 Lewis 等：Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401)；[S14 NeurIPS 2020：RAG 论文正式版本](https://proceedings.nips.cc/paper/2020/file/6b493230205f780e1bc26945df7481e5-Paper.pdf)；[S15 教师布置的《课程大作业：三张活地图》](assignment.txt)



### 资料与版本｜哪份文件现在有效？

内容性质：样本设计判断。

含义：资料除了正文，还要保存来源、发布日期、适用课程、版本和访问范围。相关不代表有效。

作用与关系：若新旧通知同在库里，只按相似程度查找可能找出过期规则。

例子：合成实验中，旧版和新版都包含“提交截止”，但只有新版适用于当前任务。

局限：发布日期较新也不必然替代旧版；需显式说明适用范围与替代关系。

学习基础：会读文件、理解结构化字段；CS106A 可作编程入口。

下一步：给十份获授权资料做来源清单，并人工标记版本替代关系。

来源：[S15 教师布置的《课程大作业：三张活地图》](assignment.txt)；[S16 样本合成实验：资料、问题与评价规则](experiment.json)



### 切分与定位｜把段落与出处一起保留

内容性质：样本设计判断。

含义：把长文分为可检索的片段，同时保留标题、页码或章节锚点。切分单位应尽量保留一个完整意思。

作用与关系：太短可能拆开条件与结论，太长可能混入无关规定。

例子：“补交条件”不能只留下“允许补交”，却丢掉“仅限事先请假者”。

局限：不存在脱离文档结构和任务的通用最佳长度；不能把某个数字当成固定标准。

学习基础：字符串与列表处理；理解文档的标题层级。

下一步：对同一文档比较按段落切分与定长切分，记录哪一种丢失了条件。

来源：[S12 InfiniFlow：RAGFlow](https://github.com/infiniflow/ragflow)；[S15 教师布置的《课程大作业：三张活地图》](assignment.txt)



### 检索｜从许多片段中找候选

内容性质：文档支持。

含义：先从资料中选出可能支持回答的片段。关键词路线重视字面匹配，向量路线比较文本表示的相近程度，两者可以互补。

作用与关系：生成模型只能利用实际拿到的证据；找不到正确资料时，换提示词也可能无济于事。

例子：“什么时候交”和“提交截止时间”用词不同；语义检索可能提供帮助，但仍需本地评测。

局限：分数高不是事实正确的证明；向量也可能误解数字、否定词和版本。

学习基础：会用列表与字典；向量路线可再学向量与相似性。

下一步：用带证据标注的十个问题比较关键词、向量和混合检索。

来源：[S02 Sentence Transformers：Retrieve & Re-Rank](https://www.sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html)；[S09 Introduction to Information Retrieval：教材与 CS276 课件](https://nlp.stanford.edu/IR-book/newslides.html)



### 文本嵌入｜用向量表示文本

内容性质：文档支持。

含义：编码器把文本变成数值向量，以便搜索相似内容。BGE 是可以进一步查看的模型家族；选型要核对语言、任务和模型卡。

作用与关系：帮助连接字面不同、含义接近的表达。

例子：“要交哪几样”和“提交材料清单”有机会在向量空间靠近。

局限：距离接近不等于证据支持；语义相近的旧通知可能仍然排在前面。

学习基础：向量、内积、归一化；MIT 18.06 是自主拓展入口。

下一步：先画三条二维向量并比较夹角，再尝试模型示例。

来源：[S02 Sentence Transformers：Retrieve & Re-Rank](https://www.sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html)；[S04 FlagOpen：FlagEmbedding](https://github.com/FlagOpen/FlagEmbedding)；[S05 Chen 等：M3-Embedding（BGE-M3）](https://arxiv.org/abs/2402.03216)；[S08 MIT OCW：18.06 Linear Algebra](https://www.ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)



### 重排｜对少量候选再比较

内容性质：文档支持。

含义：检索先快选候选，重排再细看“问题—片段”是否匹配。交叉编码器是常见实现之一。

作用与关系：让更有用的片段进入有限的上下文。

例子：检索出十段作业资料后，把真正讨论“期末提交”的段落排在“中期提交”前。

局限：增加计算和延迟，无法找回候选集中完全缺失的证据。

学习基础：理解候选集和排序；不要求现在推导网络结构。

下一步：固定候选集，对比重排前后证据顺序与耗时。

来源：[S02 Sentence Transformers：Retrieve & Re-Rank](https://www.sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html)



### 生成与拒答｜有证据才回答

内容性质：样本设计判断。

含义：把问题和有效证据交给生成模型，要求答案中的重要说法能定位到片段。资料不足时，说明缺什么。

作用与关系：把“流畅”与“有依据”分开。

例子：资料只说明提交物，没写截止时间，就回答“现有资料未说明截止日期”，不能补一个日期。

局限：仅写“请勿编造”无法保证安全；还需要引用核查、测试和人工抽查。

学习基础：理解提示词、输入上下文与输出；高级训练是后续拓展。

下一步：为有证据、证据冲突、无证据三类问题各准备样例。

来源：[S01 Lewis 等：Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401)；[S06 Es 等：Ragas: Automated Evaluation of RAG](https://arxiv.org/abs/2309.15217)；[S15 教师布置的《课程大作业：三张活地图》](assignment.txt)



### 引用与核查｜这句话来自哪一段？

内容性质：样本分析。

含义：引用至少有两层检查：链接是否能打开，原文是否真正支持这句话。显示来源编号只是起点。

作用与关系：用户要能检查范围、条件、版本和结论，而不是看到引用就被迫相信。

例子：旧版说“10月20日”，新版说“10月27日”。旧版链接即使真实，也不能支持当前截止日期。

局限：需要逐句检查关键结论；自动评价也可能误判。

学习基础：能区分事实、引用和解释。

下一步：为每个关键说法保存 claim、source、定位和适用条件。

来源：[S06 Es 等：Ragas: Automated Evaluation of RAG](https://arxiv.org/abs/2309.15217)；[S15 教师布置的《课程大作业：三张活地图》](assignment.txt)；[S16 样本合成实验：资料、问题与评价规则](experiment.json)



### 分层评价｜哪里对，哪里错？

内容性质：论文支持 + 样本规则。

含义：分别看“找没找到有效证据”和“答案是否得到证据支持”，再看响应时间与使用体验。不要只用一个总分解释所有失败。

作用与关系：同一句错答案，可能来自缺资料、检索失误、版本错误或生成曲解。

例子：本样本实验计算 Evidence Hit@1：排名第一的片段是否为人工标注的有效证据。它不是答案正确率。

局限：小样本与合成数据只验证机制，不能代表真实学校的使用效果。

学习基础：计数、分母、对照变量；后续再学统计推断。

下一步：收集十个获授权的真实问题；锁定测试集，记录失败原因。

来源：[S06 Es 等：Ragas: Automated Evaluation of RAG](https://arxiv.org/abs/2309.15217)；[S16 样本合成实验：资料、问题与评价规则](experiment.json)



### Faiss｜搜索向量的库

内容性质：官方仓库支持。

含义：用于稠密向量的相似性搜索与聚类。它负责索引和查找，不负责独立理解文件、生成答案或管理整套权限。

作用与关系：把“编码文本”和“快速搜索编码结果”拆成两个环节。

例子：先用嵌入模型得到片段向量，再用 Faiss 找到接近问题向量的片段。

局限：需要另外处理文档、元数据与权限；小资料集可以先直接比较向量。

学习基础：Python、数组、向量距离；正式集成属于自主拓展。

下一步：读官方入门，先比较精确搜索与近似搜索的时间、内存和召回。

来源：[S03 Meta / facebookresearch：Faiss](https://github.com/facebookresearch/faiss)



### 编排工具｜Dify / RAGFlow

内容性质：官方仓库支持。

含义：平台能帮助组织知识库、模型调用和工作流，也可以自行编写程序。选择取决于团队能否维护与解释数据流。

作用与关系：降低集成门槛，同时让团队关注检索、引用、权限和评价。

例子：可用平台搭原型，再用同一测试问题与手写基线比较。

局限：样本没有实际部署这两个平台；不根据功能清单宣称效果更好。许可、资源条件需逐项核对。

学习基础：先画清输入、存储、检索、模型和输出的流程。

下一步：只选一条路线做小原型，记录维护成本与失败案例。

来源：[S11 LangGenius：Dify](https://github.com/langgenius/dify)；[S12 InfiniFlow：RAGFlow](https://github.com/infiniflow/ragflow)

## 3. 生态地图：谁推动，关系怎样运转

### Lewis 等作者团队｜RAG 代表性早期研究

性质：发表时事实。Patrick Lewis 等在 2020 年的代表性工作中结合检索与生成，研究知识密集型语言任务。入选是因为它帮助理解路线的来由。

入选理由：以一项具体成果作为研究入口，而非给学者排名。

具体例子：从论文研究问题出发，回到领域地图的“RAG”和“检索”节点。

范围与限制：不把 2020 年作者署名单位当成当前任职；不把早期贡献说成独占整个方向。

后续核查：核对论文作者页、发表版本和实验任务。

来源：[S01 Lewis 等：Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks](https://arxiv.org/abs/2005.11401)；[S14 NeurIPS 2020：RAG 论文正式版本](https://proceedings.nips.cc/paper/2020/file/6b493230205f780e1bc26945df7481e5-Paper.pdf)



### FlagOpen 社区｜FlagEmbedding / BGE

性质：官方仓库支持。FlagEmbedding 仓库提供检索相关模型与使用入口，BGE-M3 论文是理解多语言表示的一条路径。

入选理由：把嵌入概念连接到真实可查看的模型、代码和论文。

具体例子：为中文课程检索选择候选编码器时，可把 BGE 放进待评测集合。

范围与限制：这里不宣称任何模型当前排名第一；具体模型许可和硬件需求需另查。

后续核查：查看模型卡和示例，使用同一测试集进行比较。

来源：[S04 FlagOpen：FlagEmbedding](https://github.com/FlagOpen/FlagEmbedding)；[S05 Chen 等：M3-Embedding（BGE-M3）](https://arxiv.org/abs/2402.03216)



### Sentence Transformers｜编码与重排工具生态

性质：官方文档支持。官方示例把双编码器检索与交叉编码器重排串起来，是理解“两阶段搜索”的可操作入口。

入选理由：同一文档能够连接知识解释、工程实现和学习路径。

具体例子：先通过双编码器找候选，再用交叉编码器比较问题和候选。

范围与限制：示例模型和英文样例不能直接证明中文课程检索表现。

后续核查：阅读示例的数据流，先解释每一步，再考虑复现。

来源：[S02 Sentence Transformers：Retrieve & Re-Rank](https://www.sbert.net/examples/sentence_transformer/applications/retrieve_rerank/README.html)



### Meta / Faiss 社区｜提供相似性搜索基础设施

性质：官方仓库支持。Faiss 仓库说明该库主要由 Meta 的 FAIR 团队开发，并列出贡献者与技术文档。

入选理由：它代表底层基础设施，而非最终用户产品。

### 本次实际运行的微型实验

全部为合成资料，不代表真实学校。6 条资料，4 个问题，人工给定适用项目和当前有效版本，固定字符特征和余弦打分。仅比较是否先筛选 current 元数据。

- A-old｜项目A｜已被替代：项目A的提交截止时间是10月20日。提交截止时间以本通知为准。

- A-new｜项目A｜当前有效：项目A补充通知：原截止安排已调整，最终上交日期为10月27日。

- A-format｜项目A｜当前有效：项目A提交材料应包含网站链接和更新记录。

- B-old｜项目B｜已被替代：项目B展示时长为5分钟，展示时长不要超出。

- B-new｜项目B｜当前有效：项目B更新说明：本次汇报改为8分钟，替代此前的演示安排。

- C-current｜项目C｜当前有效：项目C提交材料为一份PDF文件。



- Q1：项目A的提交截止时间是什么？ 相关性第一名 A-old；先筛有效版本后的第一名 A-new；有效证据标签 A-new。

- Q2：项目B展示时长是多少分钟？ 相关性第一名 B-old；先筛有效版本后的第一名 B-new；有效证据标签 B-new。

- Q3：项目A提交材料包含什么？ 相关性第一名 A-format；先筛有效版本后的第一名 A-format；有效证据标签 A-format。

- Q4：项目C提交材料是什么？ 相关性第一名 C-current；先筛有效版本后的第一名 C-current；有效证据标签 C-current。



结果：相关性基线命中 2/4；先筛有效版本后命中 4/4。指标为 Evidence Hit@1 = 排名第一的片段是人工标注有效证据的问题数 / 4。不是生成答案正确率。

结论：旧通知可因词面更接近而排在新版之前。版本有效性需要单独处理；引用能打开不代表引用适用于当前问题。

限制：仅 4 个刻意包含版本冲突的合成问题；没有语言模型生成、真实学生、独立盲测或性能测试，不能据此估计生产系统提升幅度。

- 先定义问题 → **将任务拆为环节** → 系统观：定位瓶颈（样本分析；S15）。

- 系统观：定位瓶颈 → **定位后再选方案** → 多目标取舍（样本分析；S02）。

- 发展观：方法为何出现 → **新证据触发更新** → 成长与协作（行动建议；S15）。



## 6. 地图 AI：实际实现与边界

浏览器内有实际运行的轻量机器学习：用 75 条内置标注短句训练多项式朴素贝叶斯，识别“概念解释、学习路径、路线比较、来源关系、适用边界”五类意图；使用字符及字符二元组特征、拉普拉斯平滑。节点检索用 TF-IDF 余弦与名称匹配；答案摘取地图字段并返回节点和来源。比较路线有固定模板。它不是大语言模型，也不是已经上线的课程 RAG 产品。

可以演示：RAG 是什么？比较关键词检索和向量检索。文本嵌入需要什么课程基础？Faiss 有哪些局限？我们学校应该上什么课？最后一个问题应明确无法确认本校课程，而不是编造名称。

局限：小训练集，意图与检索可能出错；不联网查新，不能判断外部网页实时状态；没有大模型生成。若教师要求大模型 API，需另接服务端模型，密钥留在服务端，保留证据引用、拒答与限流，不向同学索取密钥。



## 7. 保持地图活起来

节点可在浏览器中修改，并要求填写依据与原因；改动标注为待核实。更新和反馈表保存到 localStorage，可导出 JSON。它们不会自动同步到其他设备，维护者需要核实后发布新版本；当前没有共享数据库和自动新闻抓取。

每周流程：检查论文、仓库、课程资料与反馈 → 新线索先待核实 → 读原文或做实验 → 改内容与关系 → 记录日期、对象、依据、内容和原因 → 发布 → 验证他人访问。没有新证据时，记录检查范围与维持理由。

## 12. 文件与使用

- `dist/index.html`：交互网站入口，双击可离线查看内置内容。

- `dist/data.js`：节点、带类型关系、公开课程路径、来源与计划。

- `dist/engine.js`：意图训练样本、朴素贝叶斯、节点检索与有据摘录。

- `experiment.cjs`：根目录运行 `node experiment.cjs` 可重算实验；发布目录中的同名脚本可与 engine.js 放在同一文件夹运行。

- `verify.cjs`：根目录运行 `node verify.cjs` 检查关系、来源与基本问答。

- `dist/experiment.json`：原始合成资料、每题排名、规则与结果。

- `dist/verification.json`：开发验证，不是同学互评。

- 本地修改通过网页的导出按钮保存，不会自动写回 data.js 或更新云端。
